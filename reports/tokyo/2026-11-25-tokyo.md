## 4. T3: real-time paper trader (paper only)

**Code.** `lp_arb/paper.py` (one asyncio process), `lp_arb/paper_vs_shadow.py`, unit `deploy/lp-arb-paper.service` (Restart=always, Nice=10, MemoryMax=300M, CPUQuota=25%).
- **Feeds:** the Lighter read-only websocket (order book + trades for the live BTC 15m market, found every 20 s via `GET /api/v1/events?tag=btc-updown-15m`; `bo_market_stats/all` for outcomes) and one Polymarket market-websocket connection per window for its Up token (tokens and fee rate from Gamma by slug). It rolls to the next window by itself.
- **Trigger:** on every book update from either venue it evaluates the frozen trigger with the frozen constants (TH 0.04, ≥ 5 shares, start + 5 s, the 1 s hedge must land before the last grid point, 500 ms per-side pause after a trigger, 5 s after a Lighter fill, clip ≤ 200). It logs `trigger` (local time, both exchange timestamps, side, Lighter px/size, PM px/size, both books, pair cost after fees). Then `check` lines at +100/+300/+500 ms (+500 displayed = paper Lighter fill, the frozen condition), and `hedge` at +1000 ms (PM price, size, qty, P&L per share). `settle` lines come after both venues resolve.
- **Paper only.** No signing library is imported and no order endpoint is called. `live_lighter_ioc()` and `live_pm_fak_hedge()` raise `NotImplementedError`. The probe caps from `frozen/t1_shadow_candidate.json` sit beside them as constants (5 shares/leg, 20 pairs/day, $25 open cost, PM limit = ask + 1¢, BTC only, stop at > 10% unhedged or < 0 after 50 pairs).
- **Logs:** `~/lp-arb/paper/YYYY-MM-DD.jsonl`, a new file per UTC day, capped at 200 MB/day, files older than 60 days deleted. Reconnect with exponential backoff (1 → 30 s, jitter). Every message handler is wrapped, so a bad message becomes an `error` line, not a crash. A `health` line every 60 s carries message counts, reconnects, lag p10/p50/p90 for both venues, errors and RSS.
